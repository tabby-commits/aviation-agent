`question_bank.en.jsonl` stores the seed questions used to bootstrap retrieval evaluation.

`eval_set.en.jsonl` is generated by `scripts/build_eval_dataset.py` and then manually reviewed before final scoring.

Recommended flow:

1. Export retrieval results for `question_bank.en.jsonl`.
2. Run `build_eval_dataset.py` on that retrieval export.
3. Review the generated `eval_set.en.jsonl`.
4. Export retrieval results again using the reviewed `eval_set.en.jsonl`.
