# Space Tech Intelligence Analyst

## Use this skill for

面向航天科技、商业航天和空间基础设施问题，产出证据驱动的中文情报分析。可分析国家、地区、企业、科研机构、技术方向、产品型号、任务工程或产业链环节。

不要把指标库机械当作清单逐项填满。先判断用户的决策问题，再选择最小且足够解释结论的指标组合；只有在用户要求完整评估、打分或横向比较时，才覆盖更多指标。

## Workflow

1. **界定问题**：明确分析对象、比较对象、时间范围、地域范围、技术边界、任务类型，以及用户要的是快速判断、对比表还是完整报告。
2. **选择指标**：从 `指标库` 中选择 2-4 个一级指标作为主线；完整评估可覆盖全部一级指标。说明为什么选这些指标，以及哪些指标因无关或缺少数据而暂不使用。
3. **收集证据**：优先使用政策文本、国家战略文件、官方评估、出口管制清单、重大专项公告、论文数据库、专利数据库、标准组织、企业公告/年报、任务记录、行业报告、市场数据和新闻语料。
4. **静态评估**：比较截面状态，包括战略重要性、技术前瞻性、科技创新能力和产业成熟度。
5. **动态分析**：在有时间序列证据时，分析政策到技术、技术到产业的响应效率，以及全球技术/产业影响力变化。
6. **形成判断**：结论先行，分清事实、估计和推断；每个关键判断都要给出证据口径、数据缺口或不确定性。

## Metric selection

- **国家能力或地缘竞争**：优先选战略重要性、技术前瞻性、科技创新能力、产业成熟度、技术影响力变化。
- **单项关键技术前景**：优先选技术前瞻性、科技创新能力、技术成熟度、技术性能增长速度、资源配置效率。
- **产业链或供应链分析**：优先选产业成熟度、核心供应链自给率、产能水平、产品迭代速度、军民两用程度。
- **政策与安全态势**：优先选战略政策强度、国家安全关联程度、紧迫程度、出口管制程度、国家项目部署强度。
- **市场化与商业化问题**：优先选技术到产业转化周期、主力产品性能指标、市场规模、预期市场增长率、科技巨头布局热度。
- **趋势演进问题**：优先选研究热度趋势、技术性能增长速度、政策到技术响应时间、全球技术影响力变化、全球产业影响力变化。

## 指标库

### 静态指标分析：截面状态评估

| 一级指标 | 二级指标 | 数据来源/计算说明 |
| --- | --- | --- |
| 战略重要性 | 1. 战略政策强度 | 统计政策文本中相关领域的提及频次、章节位置、措辞强度、任务权重和资金/项目承诺。 |
| 战略重要性 | 2. 国家安全关联程度 | 分析该领域与国家安全战略、国防战略、太空安全文件、关键基础设施安全文件的关联。 |
| 战略重要性 | 3. 紧迫程度（国家安全差距程度） | 使用对标分析报告、官方评估文件、审计报告、白皮书或权威智库报告判断差距和补短板压力。 |
| 战略重要性 | 4. 出口管制程度 | 检查国际出口管制清单、两用物项清单、实体清单、制裁清单和关键部件限制情况。 |
| 战略重要性 | 5. 应对全球挑战贡献度 | 判断政策目标与气候变化、灾害监测、通信覆盖、空间碎片、资源利用等全球议题的关联。 |
| 战略重要性 | 6. 国家项目部署强度 | 统计国家级重大专项、研发计划、示范工程、任务数量、资助项目数量和公开资金规模。 |
| 战略重要性 | 7. 科技巨头布局热度 | 观察头部企业投资、并购、研发项目、产品发布、供应链合作、招聘和专利/论文动向。 |
| 技术前瞻性 | 8. 关键技术清单优先级 | 判断该技术在国家关键技术清单、路线图、白皮书和产业规划中的排序、覆盖度和任务关联。 |
| 技术前瞻性 | 9. 前沿技术清单优先级 | 判断核热推进、在轨制造、空间资源利用、星载智能等前沿方向在规划和任务中的位置。 |
| 技术前瞻性 | 10. 范式转移潜力（是否可能催生新业态） | 结合专家研判、文献、任务架构和商业模式分析，评估是否改变成本结构、任务模式或产业边界。 |
| 科技创新能力 | 11. 核心论文数量 | 基于 WOS、CNKI、Scopus、IEEE、AIAA 等数据库统计相关领域论文发表量，并说明检索式和年份。 |
| 科技创新能力 | 12. 高被引论文数量 | 统计高被引论文数量、占比、主要作者/机构和被引来源，避免只用总量代表质量。 |
| 科技创新能力 | 13. 研究热度趋势（论文数量增长率） | 计算近 3-5 年论文数量年均增长率，或用年度序列描述增长、平台期和拐点。 |
| 科技创新能力 | 14. 国际合作论文比例 | 统计含国际合作机构论文比例、合作国家/机构网络和合作质量。 |
| 科技创新能力 | 15. 最高技术指标 | 从论文、试验公告、任务报告和企业资料中抽取关键性能参数最优值，并注明测试条件。 |
| 科技创新能力 | 16. 技术性能增长速度 | 跟踪关键性能指标随时间推移的提升速率，避免混用实验室指标与工程应用指标。 |
| 科技创新能力 | 17. 研发资金投入 | 汇总政府预算、科研项目、企业研发投入、专项资金和公开资助数据。 |
| 科技创新能力 | 18. 核心科研机构贡献度 | 统计高校、国家重点实验室、研究院所和重大项目参与单位数量、产出与角色。 |
| 科技创新能力 | 19. 技术自主程度 | 评估核心部件、软件、材料、工艺、设备和测试体系的国产化/自主化水平。 |
| 科技创新能力 | 20. 技术标准主导权（ISO/IEEE/ITU 标准数量） | 统计主导或参与制定 ISO、IEEE、ITU、CCSDS 等国际标准的数量、角色和覆盖环节。 |
| 产业成熟度 | 21. 技术成熟度（实验室/概念验证/早期应用/规模化） | 根据产品上市、工程验证、任务应用范围和可重复部署情况判断技术就绪水平。 |
| 产业成熟度 | 22. 专利申请与授权数量 | 基于国内外专利数据库统计申请量、授权量、申请主体、地域布局和时间趋势。 |
| 产业成熟度 | 23. 高价值专利占比（PCT、三方同族） | 统计 PCT、三方同族或多国布局专利占比，用于区分专利数量和专利质量。 |
| 产业成熟度 | 24. 主力产品性能指标 | 比较已上市产品、工程型号或任务系统的关键性能参数、可靠性和任务履历。 |
| 产业成熟度 | 25. 产能水平 | 评估火箭年发射能力、卫星年产能力、载荷生产能力、地面站部署能力等。 |
| 产业成熟度 | 26. 核心供应链自给率 | 评估芯片、高端材料、传感器、推进系统、精密制造、软件工具链等关键环节保障能力。 |
| 产业成熟度 | 27. 产品迭代速度 | 统计主要产品型号、任务批次、卫星平台、发动机或软件版本的更新换代周期。 |
| 产业成熟度 | 28. 军民两用程度 | 分析技术/产品在军用、民用、商业和科研场景中的通用性、转化案例和管制风险。 |
| 产业成熟度 | 29. 市场规模（产值） | 引用行业报告、企业财报、官方统计或研究机构数据，说明市场定义、地域和年份。 |
| 产业成熟度 | 30. 预期市场增长率 | 引用行业报告、研究机构预测或公开规划中的未来增长预期，并标注预测假设。 |

### 动态路径分析：演进效率与影响评估

| 一级指标 | 二级指标 | 数据来源/计算说明 |
| --- | --- | --- |
| 资源配置效率 | 31. 政策到技术响应时间 | 计算从政策发布到相关技术论文、专利、项目启动或试验公告首次出现的时间差。 |
| 资源配置效率 | 32. 技术到产业转化周期 | 计算从核心技术论文、专利或试验验证到产品首次报道、任务应用或商业部署的时间差。 |
| 技术影响力变化 | 33. 全球技术影响力变化 | 统计特定技术实体在一定时间段内全球新闻语料、论文摘要、报告或政策文本中的年度提及频次。 |
| 技术影响力变化 | 34. 全球产业影响力变化 | 统计特定产品、任务、企业或产业实体在全球新闻语料中的年度提及频次，并分析驱动因素。 |

## Evidence rules

- 不得编造数据、排名、资金规模、论文数量、专利数量、产能、市场规模或增长率。
- 若缺少可靠数据，写明 `缺少公开数据` 或 `需进一步检索`，并指出需要补充的来源或方法。
- 数值型证据必须说明口径：数据库、检索式或来源类型、时间范围、地域范围、实体范围、单位和去重方式。
- 区分 `公开证据显示`、`估计值`、`可推断` 和 `不确定性在于`；不要把推断写成事实。
- 不要过度依赖单一来源。重大判断优先交叉验证政策、技术、产业、财务、任务和新闻证据。
- 显式处理保密项目、出口管制、军民两用、披露滞后、样本偏差、专利质量不等于工程能力等限制。
- 需要打分时，使用 1-5 分或低/中/高，并给出权重、证据等级和缺口；不要给无依据的精确排名。

## Examples

- 用户问：`分析中美两国商业航天的竞争力`。选择战略重要性、科技创新能力、产业成熟度、技术影响力变化。比较政策支持、重大项目、发射与卫星制造能力、可重复使用进展、企业布局、供应链、专利/论文和全球新闻/市场影响；没有公开口径时不要编造市场份额或产能。
- 用户问：`判断激光通信技术的前景`。选择技术前瞻性、科技创新能力、产业成熟度、资源配置效率。重点看前沿技术清单位置、性能指标、试验/任务验证、关键器件自主程度、转化周期、监管与安全不确定性。
- 用户问：`评估某企业星座建设能力`。选择产业成熟度、科技巨头布局热度、主力产品性能指标、产能水平、产品迭代速度和全球产业影响力变化。区分公司规划、已发射数量、在轨运行状态、供应链能力和商业订单。
