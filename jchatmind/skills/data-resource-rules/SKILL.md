# 数据资源检索与使用规则

## 可用资源与适用范围

| 资源 | 访问方式 | 适用 | 优先级 |
|---|---|---|---|
| 论文元数据（5899 条，含筛选结论） | PaperSearchTool | 指标(9)(11)(12)(16) 的证据汇集；按国别/年份/状态过滤 | 数值类证据第一优先 |
| 参数证据（1443 条人工审核） | ParameterEvidenceTool | 指标(13)(14) 性能参数；每条带证据原文+页码 | 性能数值唯一来源 |
| 技术分类（1 层 6 类 + 4488 篇归属） | TaxonomyBrowseTool | 按技术层级组织证据、选择分析范围 | 限定分析范围时先查 |
| 文献计量（公式计算） | BibliometricTool | 指标(9)-(12)(16) 的计算结果 | 计算类结论唯一来源 |
| 论文全文（RAG 分块） | KnowledgeTool（论文 KB） | 方法细节、实验设置的原文语境 | 1-4 不够时深入 |
| 新闻语料（RAG） | KnowledgeTool（新闻 KB） | 产业事件、企业动向、政策线索（指标 5/26） | 产业/动态类证据 |
| 外部 Web | WebSearchTool（可限时间范围与域名） | 更新信息、权威原文回查、政策文件 | 补充与核验，最后用 |

## 调用顺序规则

1. **数值与统计优先走结构化资源**（PaperSearch/ParameterEvidence/Bibliometric），不从新闻或网页推算论文数、参数值。
2. **年份/国别/技术层级过滤**在结构化查询里完成，不在结果上人工筛选。
3. **RAG 检索**（论文/新闻 KB）用于定性证据与语境；命中的分块只代表相关页，引用时注明页码。
4. **外部检索**仅当本地资源无覆盖（如 2026 年新政策、企业最新动态）或需核验转述时使用；查询限定时间范围，优先政府/机构/企业官网域名。
5. **冲突处理**：结构化表与新闻/网页冲突时以结构化表为准并记录差异；两新闻互斥时标注矛盾不下结论。

## 数据口径说明（必须随结果说明）

- 论文集合：WoS 6430 行去重 5430 篇 + CNKI 469 篇；有效研究论文（included）557 篇（CN 465 / US 92，含人工国别判定）。
- 参数证据：来自 313 篇论文的 1443 条人工审核记录；参数族为英文规范名（如 latency and delay）。
- 技术归属：EASC 一级类目映射的 6 类，覆盖分类语料 4488 篇（注意：归属集与 557 篇有效论文集分属不同筛选管线，交集有限，分类限定统计时需说明）。
- 论文全文：included 论文按页切分，背景/综述/参考文献章节不入库；分块元数据含 docId 与页码。

## 引用格式（每个关键判断必须带引用）

- 论文：`[docId] 标题（第一作者国别, 年份）`，例：`[WOS:001094862603092] Optimizing Federated Learning...（US, 2023）`
- 参数：`证据原文摘录 + [docId] 第N页`，必须含页码
- 全文分块：`[docId] 第N页`
- 新闻：`文档名/分块标识 + 检索词`（KB 命中）或 `URL + 检索日期`（外部）
- 计算结果：`工具名 + 输入参数（年份区间/过滤条件）`，例：`BibliometricTool(2015-2025, included)`

## 禁止事项

- 不得编造论文数、参数值、机构、日期、排名。
- 不得把参数证据的数值跨论文直接比较排名（除非条件一致性已核验——当前严格可比对为 0）。
- 不得引用未检索到的来源；每个数值都能回查到 docId/页码/URL。
- 转述材料（新闻、综述）中的数值不得直接引用，须回查原始来源或标注"转述未经核验"。
