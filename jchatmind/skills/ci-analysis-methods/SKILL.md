# 竞争情报分析方法

## 五类方法与适用条件

| 方法 | 适用条件 | 操作要点 |
|---|---|---|
| 文献计量 | 论文数量/被引/合作/机构类问题 | 只用 BibliometricTool 计算结果；说明检索边界、计数口径（完全/分数）、引用窗口；样本量小时（组内<10）高被引不产出 |
| 内容分析 | 政策文本、任务材料、新闻事件 | 预先定义编码维度（主体—行动—对象—时间）；保留原文证据；同一事件多源转载合并计一次 |
| 比例比较 | 两国同类指标的相对水平 | 先核对口径一致（同一分母、同一时间窗、同一统计单位）；口径不一致只描述不比较；比例差异给出基数 |
| 时间路径分析 | 演进过程、响应速度、阶段划分 | 事件按发生时间排序；区分"首次出现"与"规模化"；拐点需指出驱动证据 |
| 定性研判 | 证据不足或多源矛盾时的综合判断 | 结论分层：公开证据显示 / 可推断 / 存在不确定性；每层给依据 |

## 跨来源参数比较的口径核对清单（指标 13/14 前必查）

对每条要比较的参数记录，逐项核对并写进分析：

1. □ 技术对象一致（同一系统/方法/型号，或功能等价）
2. □ 任务/场景一致（业务类型、负载、拓扑）
3. □ 数据集一致（名称、规模、划分）
4. □ 硬件/网络环境一致（算力、链路、丢包条件）
5. □ 基线方法一致或可比
6. □ 结果形式一致（均值/最优值/区间，单位已归一）
7. □ 测量口径一致（仿真/实测/外场）

任何一项不满足 → 不可直接比较，只并列呈现并注明差异。当前库内严格可比的中美数值对为 0 组——这是结论而非缺陷，如实呈现。

## 证据分级与表达规范

| 层级 | 含义 | 表达方式 |
|---|---|---|
| 事实 | 结构化表/RAG 命中的原文 | "公开证据显示…（[docId] 第N页）" |
| 计算 | 工具按公式算出 | "按 BibliometricTool 计算…（口径：…）" |
| 推断 | 由事实/计算外推 | "可推断…，依据是…" |
| 缺口 | 无数据支撑 | "缺少公开数据；需补充…来源" |

禁止把推断写成事实；禁止无引用的数值；同一报告内口径表述保持一致。

## 中美比较的注意事项

- 分母用各自全量（如 CN 465 / US 92 篇有效论文），不得混用。
- 数量差异与结构差异分开解释（总量领先≠质量领先，配高被引占比/机构集中度佐证）。
- CNKI 与 WoS 覆盖差异（中文期刊 vs 国际期刊）是系统性偏差，比较时注明。
- 合作论文在完全计数中双方都计，分数计数才去重——两种口径都报告。
- 时间敏感结论标注数据截止时间；新闻类证据标注报道日期。

## 分析过程记录

为便于复核，分析过程保留：问题分解 → 指标选择理由 → 每次检索（工具+参数）→ 命中证据 → 计算结果 → 结论推导链。矛盾证据单独列出，不静默丢弃。
