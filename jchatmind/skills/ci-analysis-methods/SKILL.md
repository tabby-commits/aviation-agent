# 竞争情报分析方法

## 方法选择总则

先调用 `competitiveness-framework` 按当前问题选择指标，再调用 `data-resource-rules` 固定本轮 `snapshot_id` 和证据范围。根据问题选用论文计量、论文参数、工程部署、回收复用、发射频次、产品迭代、主体与应用等方法；没有结构化事件表时，仅逐项描述原网页支持的事实或媒体转述，不计算事件总数、国别规模或频次。不执行论文与新闻之间的相关、因果、领先滞后或“相互印证”分析。

## 一、论文计量（文献计量）

### 指标 9：核心论文数量

- 论文数按唯一论文标识去重。
- 完全计数：一篇论文只要含目标国家或机构即计 1。
- 分数计数：一篇论文在国家或机构间分配权重，单篇权重合计为 1。
- 输出年度与国别交叉表、总量、绝对增量，并报告样本边界。

### 指标 10：高被引论文数量与占比

- 参照组必须限定为同专题、同年份、同文献类型。
- 高被引阈值取前 10%；阈值处并列记录按分数分配，避免任意截断。
- 同时输出高被引论文数和高被引占比；说明引用截止日与小样本风险。

### 指标 11：研究热度趋势

- 输出年度论文数序列和相邻年绝对增量。
- 三年后向移动平均：`MA3_t=(N_t+N_{t-1}+N_{t-2})/3`，不足三年不计算。
- CAGR：`(N_end/N_start)^(1/(end-start))-1`；首末年均大于 0 且跨度至少 1 年时才定义。
- 2020—2025 为当前实验窗口时，必须完整列出 6 个年度，不得因零值删年。

### 指标 12：国际合作论文比例与结构

- 国际合作论文指作者地址覆盖两个及以上国家/地区。
- 比例分母为当前国别、时间和技术范围内的有效论文数。
- 完全计数用于识别参与关系，分数计数用于国家或机构贡献；二者不得混写。

### 指标 16：科研机构贡献

- 输出头部机构论文份额，并列出可解析机构地址的覆盖率。
- HHI：`HHI=sum(s_i^2)`，其中 `s_i` 为机构论文份额。
- 有效机构数：`N_eff=1/HHI`；没有可解析机构时不计算。
- 中国与美国分别计算，不用一国分母计算另一国份额。

## 二、论文参数证据与口径核对

指标 13、14 的统计单位是参数记录数，不是论文数。输出参数族、技术对象、数值、单位、测试条件、证据页码、年度分布和国别证据分布。

聚合分析先调用 `ParameterSummaryTool`，原样采用冻结结果中的论文分母、含参数论文数、参数记录数、年度和参数族分布；`ParameterEvidenceTool` 只用于补充可定位到 docId 与页码的具体例子。参数报告率只表示冻结论文中至少存在一条结构化参数证据的比例，不代表公开透明度、实证完整度、技术成熟度、证据质量或性能优势。

直接比较前逐项核对：技术对象、任务场景、数据集、硬件与网络环境、基线、结果形式与单位、仿真/实测口径。任一项不一致即不可直接排名。

严格可比对数量应由本次快照计算。没有严格可比证据时，只报告参数记录数、参数族覆盖和证据分布，不得得出中美技术性能优劣或国别排名。

## 三、新闻工程规模

工程规模主要映射指标 23，按结构化事件表计算：

先检查冻结事件和原始机构网页。只有原始材料直接支持且通过主体、日期、数值、单位和去重机器核验的事件才能进入下列计算；没有合格事件时记录排除原因，不给出国别规模或节奏结论。

- 年度发射次数：自然年内与目标星座直接相关、已完成的独立发射任务数，是流量。
- 部署批次：按任务或部署事件去重，是流量。
- 部署卫星数量：事件或年度实际部署数量之和，是流量；计划数量不得混入。
- 在轨卫星数量：特定 `as_of_date` 的存量；不同基准日不得直接比较。

必须区分 event_date、report_date 和 as_of_date，不把报道篇数当作发射次数，也不把计划、累计部署和当前在轨混为同一指标。报道数字未回查原始来源时，结论标注为新闻样本中的未核验转述。

## 四、新闻主体与应用

- 同样先检查冻结且机器核验的原始机构事件；不得从媒体候选 mention 生成主体事件数或应用事件数。
- 预先定义编码：国家、主体、行动类型、对象、应用类型、事件日期、报道日期、证据和核验状态。
- 同一事件多篇报道合并为一个 `event_id`，保留所有来源标识。
- 指标 5 输出头部主体事件数和行动类型分布；指标 26 输出应用事件数、应用类型和阶段分布。
- 结果必须限定到本次冻结的事件样本；报道篇数、事件数和主体数分别报告。
- 指标 8、25 只有在证据链完整时作条件性研判，不从单篇新闻推导范式变化或迭代优势。

## 五、证据分层与结论模板

每个结论明确区分事实、计算、推断和缺口：

| 层级 | 要求 | 推荐表述 |
|---|---|---|
| 事实 | 来自快照内结构化记录或可定位原文 | “冻结样本记录显示……” |
| 计算 | 给出公式、输入、过滤条件与 `snapshot_id` | “按……口径计算……” |
| 推断 | 写明事实基础、替代解释和适用范围 | “在该样本内可推断……” |
| 缺口 | 明确缺哪类数据以及对结论的影响 | “现有证据不足以判断……” |

## 六、主体现状卡片与差距矩阵（聊天报告管线）

### 主体现状卡片字段口径

每个主体现状子任务输出一张字段级卡片，每个字段必须挂原文连续引文与来源层级：

- plannedConstellation 规划星座规模（颗）：计划口径，不得写成已部署。
- inOrbit 在轨卫星数（颗）：存量，必须带 asOfDate 基准日；没有基准日的数值不得进入卡片或对比。
- cumulativeLaunched 累计发射卫星数（颗）：流量累计，注明口径是否含退役/离轨。
- launchCadence 发射节奏：描述性（如“平均每 X 天一次”），数字同样须有原文出处。
- latestVersion 最新版本/代际：版本节点归指标 25。
- commercial 商业化/组网里程碑：区分计划节点与已实现节点。

三态标注：fact（原始来源直述）、reported（第三方/媒体转述，正文写明“据××报道”）、planned（计划、意向、未完成）。tier 标注：official / third-party / media。原文没有的字段列 missingEvidence，不估算。

### 差距矩阵行结构

每个比较维度一列矩阵行，字段为：aspect（维度名）、usStatus（美国侧已核验事实，含数字与基准日）、cnStatus（中国侧同上）、gapStatement（差距表述）、evidenceStrength（strong=双侧官方或计算结果 / partial=含第三方转述 / insufficient=单侧或无）。

差距表述只允许两种句式：计算层给出数字时用定量句（“按已核验存量，A 侧为 B 侧的 N 倍”）；没有计算结果时用证据差句（“中方已核验证据为……，另侧缺可核验证据”）。禁止句式：“领先/落后 × 年”、无依据的定性优劣、把计划规模当作实力差距。

### 对比计算的执行边界

倍数、差值等对比数字一律由计算层统一计算：两侧字段同单位才可计算；在轨存量基准日相差超过 90 天不得计算倍数、超过 365 天不得计算任何对比；tier=media 的字段不得作计算输入。分析角色在结论句中自行计算数字视为核验不通过。

### 整体研判的推断边界

整体研判（overallAssessment）允许显式推断，但必须：以“综合判断：”开头；只做层级、结构、机制性判断（如“差距性质是运力约束而非卫星制造能力”）；不得包含任何数字、日期、倍数；每条至少挂 2 条已核验结论为依据；不得引入新事实。此规则与 28 项框架“不计算综合得分、不做总体排名”衔接：研判解释差距的结构，不评价总体强弱。

## 禁止事项

- 不计算综合竞争力得分和总体排名。
- 不把论文数量优势等同于技术性能、产能或产业优势。
- 不把参数记录数等同于性能领先。
- 不把新闻报道数量等同于真实事件总量或全行业活跃度。
- 不执行论文与新闻之间的统计相关、因果推断、领先滞后或时间对应关系分析。
- 不把未检索到公开证据解释为主体不存在相关能力。

## 过程记录

保留：问题原文、选定指标、未选指标及原因、工具与参数、`snapshot_id`、命中证据、公式输入、原始输出、结论推导链和异常。聊天中的每次请求独立获取证据并生成新版；只有预先设定的固定样本实验才让等价问法共享同一快照和计算表。
