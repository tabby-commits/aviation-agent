# 竞争力分析框架（28 项指标）

## 权威口径

本 Skill 只使用中期报告当前定义的四个一级维度、28 项指标：战略重要性、技术前瞻性、科技创新能力、产业成熟度。不得恢复已删除的动态路径 4 项指标，不使用“静态指标分析/动态路径分析”二分，也不计算综合得分或总体排名。

## 指标选择流程

1. 从用户本轮问题明确对象、国家、时间范围和技术边界；聊天报告每次使用本轮新采集并冻结的证据快照。
2. 从 28 项中选择能直接回答问题的最小指标集；不得为填满框架而使用弱证据。
3. 为每个已选指标记录：定义、数据源、统计口径、证据覆盖、允许结论和禁止结论。
4. 未选指标及原因保存在运行档案中，区分“不相关”“本阶段缺数据”“只有线索、不能核验”；正文省略没有实质分析的维度。
5. 案例结论只适用于本次冻结的低轨卫星星座网络或可复用火箭样本，不外推为整个中美航天领域的总体结论。

## 四维度 28 项指标

| 编号 | 指标 | 本阶段状态 | 最低证据与结论边界 |
|---|---|---|---|
| 1 | 战略政策强度 | 不分析 | 需正式政策文件及版本；新闻提及不能替代政策原文 |
| 2 | 国家安全关联程度 | 不分析 | 需功能等价的公开战略材料；不评价未公开军事能力 |
| 3 | 关键技术管制程度 | 不分析 | 需法规、清单、许可条件及时间版本 |
| 4 | 国家重大项目部署 | 不分析 | 需项目、预算和里程碑原始材料；新闻只作线索 |
| 5 | 头部航天主体布局动向 | 条件可分析 | 原始机构事件材料；按主体—行动—对象—时间编码并按事件去重 |
| 6 | 关键技术清单优先级 | 不分析 | 需正式关键技术清单及可比排序规则 |
| 7 | 前沿技术清单优先级 | 不分析 | 需正式前沿清单或技术预见材料 |
| 8 | 范式变革潜力 | 条件可分析 | 论文摘要和新闻中的架构、流程或应用边界变化；只作证据化定性研判 |
| 9 | 核心论文数量 | 可计算 | BibliometricTool；完全计数与分数计数，给出国别、年份和技术范围 |
| 10 | 高被引论文数量与占比 | 可计算 | 同专题、同年份、同文献类型参照组；阈值并列按分数分配 |
| 11 | 研究热度趋势 | 可计算 | 年度序列、绝对增量、三年后向移动平均；满足条件时计算 CAGR |
| 12 | 国际合作论文比例与结构 | 可计算 | 说明合作识别、分母、完全计数和分数计数口径 |
| 13 | 已公开最高技术指标 | 可定量描述 | ParameterEvidenceTool；保留对象、参数、数值、单位、条件、页码；不得跨论文性能排名 |
| 14 | 公开技术性能变化 | 条件可分析 | 同对象、同参数、同口径、同条件的跨年证据；条件不一致仅并列展示 |
| 15 | 研发资金投入强度 | 不分析 | 缺少可比投入数据、价格口径和统计边界 |
| 16 | 科研机构贡献 | 可计算 | 机构论文份额、HHI、有效机构数；同时披露地址解析覆盖率 |
| 17 | 核心技术自主控制能力 | 不分析 | 需供应依赖、知识产权和替代路径等多源原始证据 |
| 18 | 技术标准主导权 | 不分析 | 需标准提案、牵头、投票或采纳记录 |
| 19 | 技术成熟度 | 不分析 | 需统一 TRL 证据及评估主体；新闻措辞不能直接换算 TRL |
| 20 | 专利族申请与授权规模 | 不分析 | 专利库未接入；不得用论文或新闻代替 |
| 21 | 国际专利申请 | 不分析 | 需 PCT/三方专利族和同族去重数据 |
| 22 | 同类工程产品性能 | 不分析 | 需同条件、同任务、同单位的产品级原始数据 |
| 23 | 产能水平 | 条件可分析 | 原始机构工程事件；区分发射次数、部署批次、部署卫星数量和在轨卫星数量 |
| 24 | 核心供应链保障能力 | 不分析 | 需供应关系、产能、替代性和中断证据 |
| 25 | 产品迭代速度 | 条件可分析 | 需可确认的版本、部署时间和同类产品边界；不足时只列事件序列 |
| 26 | 应用拓展能力 | 条件可分析 | 原始机构应用事件；按应用类型、主体、地区和阶段编码，限定样本边界 |
| 27 | 相关产业市场规模 | 不分析 | 需同币种、同年份、同市场边界的市场数据 |
| 28 | 产业市场规模增长速度 | 不分析 | 需连续可比市场序列和明确基期 |

## 发射与在轨数量的归属

发射次数、部署批次、部署卫星数量和在轨卫星数量主要映射到指标（23）“产能水平”。它们是工程供给和任务执行事实，不属于论文性能参数，不进入指标（13）（14）的参数比较表。

- 发射次数、部署批次、部署卫星数量是期间内发生的流量。
- 在轨卫星数量是特定日期的存量，必须同时给出 as_of_date。
- 新闻报道篇数只是样本覆盖，不能充当发射次数、部署次数或事件数。

## 关键解释边界

- 指标（9）（10）：同时说明完全计数、分数计数、参照组、引用窗口和数据截止日。
- 指标（11）：首末年份论文数均为正且跨度至少 1 年时才计算 CAGR；单年区间无定义。
- 指标（13）（14）：仅在对象、单位、场景和测试条件相同时讨论严格可比参数；记录数和参数族覆盖不表示性能领先。
- 指标（16）：机构地址缺失会影响份额与 HHI，必须披露解析覆盖率。
- 指标（23）：区分流量与存量，区分事件发生日、报道日和存量基准日。
- 指标（5）（26）：必须说明冻结事件样本范围；媒体转述不能计入已核实事件。

## 比较类问题的任务拆解模式

用户问题要求比较中美（或多个主体）时，任务拆解遵循“主体枚举 × 维度矩阵”，不由模型自由发挥：

1. 先列出问题涉及的代表性主体清单（两侧各至少一个，能多列就多列，如 Starlink、Kuiper、国网/Guowang、千帆/Qianfan），每个主体带中英检索别名。
2. 每个主体恰好一个“主体现状”子任务（actor-status），覆盖规划规模、在轨卫星数、累计发射、最新版本、商业化/组网节点；现状子任务不得合并多个主体。
3. 问题涉及的每个比较维度各一个“维度比较”子任务（dimension-compare）；比较子任务不采集新证据，只使用各主体现状子任务已核验的结果和计算层输出。
4. 最少任务数 = 主体数 + 比较维度数；正文结构相应为：各主体现状卡片 → 差距矩阵 → 整体研判 → 证据缺口。
5. 本 Skill 的指标表是“本阶段可分析指标”的唯一权威清单（状态为可计算、条件可分析、可定量描述者），代码中的指标白名单应从本表解析而非另行硬编码。
