# 竞争力分析框架（28 项指标）

## 使用规则

1. **先界定问题**：明确分析对象、比较对象、时间范围、技术边界，再选指标。
2. **选最小足够组合**：按决策问题选 2-4 个指标作主线，不机械填满 28 项；用户要求完整评估时才覆盖更多。
3. **说明未选指标**：报告"指标选择"节列明未用指标及原因（无关/缺数据）。
4. **无数据不编造**：标 ❌ 的指标如用户需要，写"缺少公开数据"并指出需补充的来源；有 ✅ 工具的指标必须用工具计算，不得心算。

## 指标解释边界（易错点）

- **(9)(10) 计数口径**：完全计数=参与即计，分数计数=按机构占比；高被引参照组=同年份同文献类型，阈值处并列分数分配；引用窗口与数据截止日必须说明。
- **(13)(14) 参数可比性**：参数名称相近不等于可比——必须核对测试条件（数据集、网络环境、基线方法、结果形式）；跨论文数值直接排名是错误，除非条件一致性经人工确认。当前严格可比中美数值对为 0 组，比较时只呈现分布与证据原文。
- **(11) CAGR**：仅首末年份论文数为正且跨度≥1 时计算；单年区间无定义。
- **(16) HHI**：基于可解析机构地址，地址缺失论文会低估集中度；解释时说明覆盖口径。

## 报告结构（输出模式）

```markdown
## 问题界定
## 指标选择（选取理由 + 未选指标及原因）
## 证据与口径（每类证据的检索范围与来源）
## 分维度分析（每个指标：口径 → 证据 → 解释）
## 综合判断（优势/短板/趋势/风险，区分事实、计算、推断）
## 数据缺口与边界
```
