# 01 - Agent 基础概念 / Introduction to Agents

## 什么是 AI Agent？

AI Agent 是一种能够**自主感知环境、进行推理并采取行动**以完成目标的智能系统。它不仅仅是一个"问答机器"，而是能够：

- 规划多步骤的执行路径
- 调用外部工具获取信息或执行操作
- 根据结果调整策略
- 持续运行直到目标达成

### 普通 LLM 调用 vs Agent

```
普通 LLM 调用 (一问一答):
用户输入 ──→ LLM ──→ 回答

Agent (多步推理):
用户输入 ──→ LLM 推理 ──→ 调用工具 ──→ 获取结果 ──→ 再次推理 ──→ ... ──→ 最终回答
                ↑                                    │
                └────────────────────────────────────┘
                              (循环)
```

## Agent 的核心组件

### 1. 大语言模型 (LLM / Brain)

Agent 的"大脑"，负责理解输入、推理和生成下一步行动计划。常用模型：
- **GPT-4o** (OpenAI)
- **Claude 3.5** (Anthropic)
- **Gemini 1.5 Pro** (Google)
- **Llama 3** (Meta，开源)
- **Qwen** (阿里，中文优化)

### 2. 工具 (Tools / Actions)

Agent 可以调用的外部能力：
- 🔍 **搜索工具**：获取实时信息（如 Tavily、Serper）
- 🧮 **代码执行**：运行 Python 代码进行计算
- 📁 **文件操作**：读写文件
- 🌐 **API 调用**：与外部服务交互
- 💾 **数据库查询**：查询结构化数据

### 3. 记忆 (Memory)

Agent 存储和检索信息的能力：
- **短期记忆**：当前对话的上下文（Context Window）
- **长期记忆**：跨会话持久化的信息（向量数据库）
- **工作记忆**：任务执行过程中的中间状态

### 4. 规划 (Planning)

Agent 分解复杂任务的能力：
- **任务分解**：将大任务拆成小步骤
- **子目标生成**：设定中间目标
- **反思与修正**：评估执行结果并调整计划

## Agent 的工作流程

```
     ┌──────────────────────────────────────────────┐
     │                  Agent Loop                   │
     │                                              │
     │  1. 接收任务 (Receive Task)                   │
     │       ↓                                      │
     │  2. 分析状态 (Analyze State)                  │
     │       ↓                                      │
     │  3. 选择行动 (Choose Action)                  │
     │       ↓                                      │
     │  4. 执行行动 (Execute Action)                 │
     │       ↓                                      │
     │  5. 观察结果 (Observe Result)                 │
     │       ↓                                      │
     │  6. 是否完成? ──→ 是 ──→ 返回最终结果          │
     │       ↓ 否                                   │
     │       └────────── 回到步骤 2 ────────────────┘│
     └──────────────────────────────────────────────┘
```

## Agent 的类型

### 按架构分类

| 类型 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| **ReAct Agent** | 交替进行推理和行动 | 可解释性强 | 速度较慢 |
| **Plan-and-Execute** | 先制定完整计划，再执行 | 整体性好 | 灵活性差 |
| **Function Calling** | 通过结构化函数调用工具 | 稳定可靠 | 依赖模型支持 |
| **CodeAct** | 用代码表达行动 | 灵活强大 | 安全风险 |

### 按应用场景分类

- **问答 Agent**：检索增强的知识问答
- **编程 Agent**：代码生成、调试、审查
- **数据分析 Agent**：自动化数据探索和可视化
- **任务自动化 Agent**：RPA、流程自动化
- **多模态 Agent**：处理图像、视频、音频

## 关键术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 工具调用 | Tool Use / Function Calling | Agent 调用外部函数或 API |
| 上下文窗口 | Context Window | LLM 能处理的最大文本长度 |
| 提示词工程 | Prompt Engineering | 设计高效指令来引导 LLM |
| 思维链 | Chain of Thought (CoT) | 让模型逐步展示推理过程 |
| 向量嵌入 | Embeddings | 文本的数值向量表示 |
| RAG | Retrieval-Augmented Generation | 检索增强生成 |
| 幻觉 | Hallucination | 模型生成不准确信息的现象 |
